#  AgroCulture - Agriculture Management System

**AgroCulture** is a web-based platform developed to support farmers by providing them with digital tools to manage agricultural activities more efficiently. The platform connects farmers with relevant information and direct market access, helping improve productivity and income.

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: PHP  
- **Database**: MySQL  
- **Server**: XAMPP (Localhost Environment)

##  Responsibilities & Contributions

- Engineered a fully responsive UI using HTML, CSS, and JavaScript for cross-device compatibility.  
- Developed backend logic using PHP and MySQL for:
  - User authentication
  - Crop recommendations
  - Product listings
- Designed and structured a relational database to manage:
  - Users
  - Crops
  - Products
  - Transactions
- Configured a local development environment using XAMPP.
- Optimized user experience with intuitive navigation and a user-friendly layout, especially for rural users.

##  How to Run Locally

1. Clone the repository.
2. Open XAMPP and start **Apache** & **MySQL**.
3. Import the SQL file into **phpMyAdmin**.
4. Run the project in your browser at:  
   `http://localhost/AgroCulture`

##  Impact and Usefulness

- Empowers farmers with access to crop planning and market information.
- Enhances decision-making with smart crop and fertilizer suggestions.
- Increases income potential by reducing dependency on middlemen.
- Promotes digital transformation in agriculture, especially in rural communities.
