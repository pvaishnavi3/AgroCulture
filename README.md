** AgroCulture - Agriculture Management System**
AgroCulture is a web-based platform developed to support farmers by providing them with digital tools to manage agricultural activities more efficiently. 
The platform connects farmers with relevant information and direct market access, helping improve productivity and income.
**Tech Stack**
Frontend: HTML, CSS, JavaScript
Backend: PHP
Database: MySQL
Server: XAMPP (Localhost Environment)
** Responsibilities & Contributions**
Engineered a fully responsive user interface utilizing HTML, CSS, and JavaScript to ensure cross-device compatibility.
Developed server-side logic with PHP and integrated MySQL for secure user authentication, dynamic crop recommendations, and efficient product management.
Designed and normalized a relational database schema to efficiently store and manage data related to users, agricultural inputs, and transactions.
Configured and maintained a local server environment using XAMPP to simulate real-world deployment for testing and debugging.
Optimized user experience by implementing intuitive navigation and a user-friendly layout tailored to the needs of rural and semi-urban users.
** How to Run Locally**
Clone the repository
Open with XAMPP and start Apache & MySQL
Import the SQL file into phpMyAdmin
Run the project in your browser at localhost/AgroCulture
** Impact and Usefulness**
Empowers farmers by providing easy access to digital crop planning and real-time market information.
Enhances decision-making through intelligent crop and fertilizer recommendations based on environmental factors.
Increases profitability by enabling farmers to connect directly with buyers, minimizing reliance on intermediaries.
Promotes digital transformation in the agricultural sector, especially among rural communities, by offering an accessible and practical online solution.
